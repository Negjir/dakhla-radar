# Madar Landed Cost

Free calculator for seafood importers, from **Madar Seafood Expo** (Dakhla, Morocco).

Compares three origins side by side and shows what one reefer container of frozen sardine, mackerel, sardinella or live oysters really costs at an EU warehouse: per kilo, per carton, per can and per oyster.

- Duty, EU border-control fees and the document checklist are set from published EU rules (sources listed on the page).
- FOB price, freight, transit and broker fees are the buyer's own quotes.
- Runs entirely in the browser; nothing is sent unless the user presses Send.
- English, French, Spanish and Arabic (right-to-left).

Open `index.html` in a browser, or publish the repository with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
